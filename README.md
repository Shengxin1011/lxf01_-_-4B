# 建筑表面裂纹智能巡检系统 - 树莓派4B视觉小车 🚗

基于Jupyter Notebook开发的树莓派小车控制代码，用于建筑表面裂纹智能巡检。

---

## 📁 项目文件说明
| 文件名 | 功能描述 |
|--------|----------|
| `LOBOROBOT.py` | 封装小车运动控制函数（含电机、舵机驱动） |
| `TCP.ipynb` | 采用TCP协议传输控制指令的版本 |
| `UDP.ipynb` | 采用UDP协议传输控制指令的版本 |
| `UDP_new.ipynb` | **UDP协议优化版控制代码**，在原版基础上增加了传输高清裂纹图像的功能 |
| `setup.exe` | 配套调试工具程序 |

---

## 🛠️ 开发环境
- 硬件平台：树莓派4B + 视觉小车底盘
- 开发工具：Jupyter Notebook
- 通信协议：TCP / UDP 双版本支持

---

## 📝 使用说明
1.  确保树莓派与小车硬件正常连接
2.  运行`setup.exe`完成基础硬件调试，只能使用TCP协议进行通信，适配TCP.ipynb代码文件
3.  根据场景需求，选择TCP或UDP版本的Notebook运行控制指令
4.  调用`LOBOROBOT.py`中的封装函数，实现小车运动控制
5.  无论是TCP.ipynb还是UDP.ipynb都实现了上传实时采集视频、接收控制指令的功能。
